# 🔞 NSFW Discord Bot - Media & Entertainment Bot

A full-featured Discord entertainment bot with multimedia command handlers, image boards, and age-gated channel integrations.

## ✨ Features
- Age-gated channel verification checks (`is_nsfw`).
- Integrations with public media APIs and subreddits.
- Interactive buttons and paginated image carousels via Discord Components.

## 🚀 Run
```bash
pip install discord.py aiohttp
python bot.py
```
